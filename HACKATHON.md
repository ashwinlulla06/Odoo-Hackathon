# GlobeTrotter hackathon scope

GlobeTrotter is an India-focused itinerary planner with real authentication,
multi-city trips, catalog discovery, budgets, sharing, and an AI-assisted
planner. Gemini may propose a schedule, but deterministic validation always
runs before a proposal can be applied. A rule planner keeps the demo functional
when Gemini is unavailable.

Demo flow: create an account, create a trip, add an Indian city stop, generate
and review a proposal, apply it, inspect the itinerary and budget, then publish
the trip.
